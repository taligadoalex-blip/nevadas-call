Compartilhar tela

Escolha a fonte no seletor seguro do navegador e controle se o cursor será transmitido.

🖱️ Cursor
🔊 Áudio
🔊 Áudio: o navegador/Windows abre o seletor oficial. O site não consegue marcar ou desmarcar individualmente os aplicativos da lista “Não compartilhar som dos seguintes apps”; isso é controlado pelo navegador/Windows. Quando essa lista aparecer, deixe marcados os apps cujo som não deve sair na transmissão.

🖱️ Cursor oculto: “Ocultar cursor” envia cursor: "never" para a captura. Se o navegador/Windows respeitar essa opção, o mouse não aparece no vídeo transmitido.
💡 Importante: para mutar cada aplicativo do Windows individualmente, use o botão 🔊 Áudio do PC. No navegador ele controla somente as fontes acessíveis à página; no EXE nativo ele deve ser conectado ao mixer de sessões de áudio do Windows.

🔊 Áudio dos aplicativos

Controle o áudio que o NEVADAS CALL usa para evitar eco.

Importante no navegador: uma página HTML não tem permissão para listar e mutar individualmente todos os aplicativos do Windows. Por isso, esta aba controla as fontes de áudio que o NEVADAS CALL realmente consegue acessar. No EXE do NEVADAS CALL, esta mesma tela pode ser ligada ao mixer de áudio do Windows para mostrar os aplicativos abertos e mutar cada sessão, inclusive o próprio NEVADAS CALL.
